Capabilities

Everything an enterprise needs from applied AI.

From hybrid retrieval to agentic research, voice, and code execution — AetherSearch unifies the toolbox for grounded, auditable AI in your stack.

Agentic RAG

Best-in-class retrieval quality with hybrid keyword + vector search and AI agents that plan, retrieve, and reason.

Deep Research

Multi-step research flow that generates rigorously cited, in-depth reports — built on iterative agentic exploration.

Custom Agents

Build agents with bespoke instructions, tools, knowledge, and actions — composable for any workflow.

Live Web Search

Artifacts

Document Pipeline

From source to searchable answer — automatically.

Documents flow through a streamlined ingestion pipeline coordinated by Celery. Every step is idempotent, observable, and resumable.

Background Processing

Nine specialized workers, orchestrated by Celery.

AetherSearch separates concerns across thread-pool workers so heavy tasks never block the request path. Each worker is multi-tenant, observable, and independently scalable.

PR

Primary

4 threads · core orchestration

Coordinates connector lifecycle, vespa sync, pruning checks, and system-wide periodic tasks.

DF

Docfetching

env-tuned · per-source pulls

Pulls documents from external sources, batches them, and spawns docprocessing tasks. Watchdog monitors stuck connectors.

DP

Docprocessing

indexing pipeline core

Upserts to Postgres, chunks, contextualizes, embeds via model server, and writes to Vespa.

LT

Light

high concurrency · <1s tasks

Vespa metadata sync, doc permission upserts, checkpoint cleanup — fast tasks at high throughput.

HV

Heavy

4 threads · long-running

Connector pruning, document permissions sync, external group sync, large CSV exports.

KG

KG Processing

graph + clustering

Builds the Knowledge Graph by extracting relationships between documents and running clustering.

MN

Monitoring

single thread · observability

Tracks queue depth, process memory, system health, and Celery liveness across the cluster.

UF

User Files

user uploads · projects

Indexes user-uploaded files and synchronizes them into the project workspace they belong to.

BT

Beat Scheduler

multi-tenant cron

The DynamicTenantScheduler dispatches periodic tasks: indexing checks, sync probes, KG rounds, cleanups.
